# Jogo de Trilha

Versão digital do jogo de trilha (também conhecido como *Nine Men's Morris* ou jogo do moinho), feita para jogar no navegador com duas pessoas.

> Projeto desenvolvido como atividade individual de GitHub: estudo de um projeto aberto, fork, commits e documentação.

## Como jogar

O tabuleiro tem 24 pontos e cada jogador tem 9 peças.

1. **Colocação:** os jogadores se alternam colocando uma peça por vez em um ponto vazio.
2. **Movimentação:** quando todas as peças forem colocadas, cada jogador move uma peça por vez para um ponto vazio ligado ao seu.
3. **Moinho:** ao formar uma linha de 3 peças da mesma cor, o jogador remove uma peça do adversário.
4. **Vitória:** vence quem deixar o adversário com apenas 2 peças ou sem movimentos possíveis.

## Como executar

1. Baixe o projeto:
   ```
   git clone https://github.com/SEU-USUARIO/jogo-de-trilha.git
   cd jogo-de-trilha
   ```
2. Abra o arquivo `index.html` no navegador.

Não é necessário instalar nada.
